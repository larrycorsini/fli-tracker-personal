# Milestone v1.1: Multi-Destination Tracker

**Status:** ✅ SHIPPED 2026-06-18  
**Phase:** multi-dest-tracker (resubscoped — supersedes planned Fork Polish phases 5–8)  
**Site:** https://flights.larrycorsini.com

## Overview

Shipped an automated multi-region flight search pipeline and static Netlify dashboard. Two-phase search (SearchDates shortlist → SearchFlights detail) covers 8 destination regions from SLC/PVU origins. Daily launchd job runs search, optional iMessage alerts, HTML generation, and Netlify deploy.

## Phase: Multi-Destination Tracker

**Goal:** Track cheapest direct/one-stop fares across multiple regions with a public static dashboard.

**Depends on:** v1.0 upstream sync (fli 0.10.0 booking URLs)

**Delivered:**

1. `tracker_config.py` — 8 regions, excluded budget carriers, SLC/PVU origins, alert thresholds
2. `find_direct.py` — two-phase pipeline with retries, atomic JSON write to `best_direct.json`
3. `generate_flight_report.py` — Alpine.js + Tailwind static HTML (index, heatmap, history)
4. `alert.py` — iMessage alerts when regional prices drop below thresholds
5. `daily_flight_search.sh` — orchestration + Netlify deploy via `npx netlify-cli`
6. `public/` — generated dashboard with booking deep-links, PWA manifest, service worker
7. `netlify.toml` — publish dir, security headers, SW cache policy

**UAT:** 10/11 scenarios auto-verified; live site load pending manual check (deferred).

**Artifacts:** [v1.1-phases/multi-dest-tracker/](v1.1-phases/multi-dest-tracker/) (UI-SPEC, UAT, UI-REVIEW)
