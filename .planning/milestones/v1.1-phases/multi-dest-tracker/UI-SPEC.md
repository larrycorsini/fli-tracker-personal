# Multi-Dest Tracker — UI Design Contract

> Visual and interaction contract for the static Alpine.js + Tailwind flight tracker (`public/index.html`, `heatmap.html`, `history.html`). Generated by gsd-ui-researcher.

**Brand direction (locked):** Primary `#1F2A37`, Google Flights–inspired UX, mobile-first, booking deep-links on every fare.

**Current vs target:** Deployed UI still uses legacy purple tokens (`#BD8BCA`). This contract defines the **target palette** for the next generator pass.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (static HTML generator, not React) |
| Preset | not applicable |
| Component library | none — hand-built Tailwind + Alpine.js 3.14 |
| Icon library | Inline Heroicons-style SVG (stroke, 24×24) |
| Font | **Roboto** (Google Fonts) — weights 400, 500, 700; fallback `system-ui, sans-serif` |
| CSS delivery | Tailwind CDN + `:root` custom properties in `get_base_html_head()` |
| JS | Alpine.js 3.14 + `@alpinejs/collapse`; Chart.js on history page only |
| Breakpoints | Tailwind defaults: `sm` 640px, `md` 768px, `lg` 1024px |

## Responsive Rules

### Breakpoints

| Breakpoint | Layout behavior |
|------------|-----------------|
| **&lt; sm (&lt;640px)** | Single-column everything; nav stacks logo + links; fare rows stack price below details; time options full-width CTA; heatmap 2 cols; tabs horizontal scroll |
| **sm (≥640px)** | Nav inline; time-option rows side-by-side label + CTA; heatmap 3 cols |
| **md (≥768px)** | Hero padding increase; fare rows horizontal (airline left, price right); filters 2-column row; heatmap 4 cols |
| **lg (≥1024px)** | Expanded time grid 2 columns; heatmap 5 cols; max content width `max-w-5xl` (index) / `max-w-7xl` (nav) |

### Mobile tab scroll

- Container: `overflow-x-auto tab-scroll tab-fade` on index region tabs
- Inner nav: `flex min-w-max` with `whitespace-nowrap` tabs
- Edge fade: CSS mask `linear-gradient(to right, transparent, black 12px, black calc(100% - 12px), transparent)`
- Touch: `-webkit-overflow-scrolling: touch`; no scroll snap required
- Heatmap/history: same horizontal scroll pattern; **add `tab-fade` on index parity** (currently missing on subpages — FLAG)

### Content widths

| Page | Main section max-width |
|------|------------------------|
| index | `max-w-5xl` flights section; hero text `max-w-2xl` |
| heatmap | `max-w-5xl` |
| history | `max-w-5xl`; chart container `50vh` min 300px |

## Accessibility

### Contrast (WCAG 2.1 AA targets)

| Pair | Ratio | Pass |
|------|-------|------|
| `--text-primary` on `--surface-card` | ~16.1:1 | ✓ |
| `--text-secondary` on `--surface-card` | ~5.7:1 | ✓ |
| `--brand-primary` on `--surface-page` | ~14.2:1 | ✓ |
| `--accent-interactive` on white | ~4.6:1 | ✓ (large text / UI) |
| White on `--accent-interactive` (CTA) | ~4.6:1 | ✓ |
| White on `--heatmap-mid` (#F9AB00) | ~1.9:1 | ✗ — use `#111827` text on mid tier |
| White on `--heatmap-low` / `--heatmap-high` | ≥4.5:1 | ✓ with white; mid tier exception above |

### Focus

- All interactive elements: `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[#1A73E8] focus-visible:ring-offset-2`
- Tab buttons: visible focus ring matching accent
- Skip link (recommended): `Skip to flights` → `#flights` (not yet implemented — FLAG)

### Tabs (index — reference implementation)

```html
<nav role="tablist" aria-label="Destination regions">
  <button role="tab" :aria-selected="activeTab === 'DFW'" ...>DFW</button>
</nav>
<div role="tabpanel" x-show="activeTab === 'DFW'">...</div>
```

**Required for heatmap/history:** mirror `role="tablist"`, `role="tab"`, `:aria-selected`, and `role="tabpanel"` on region panels (currently missing — FLAG).

### Expandable fare rows

- Toggle must be `<button type="button">` or have `tabindex="0"`, `role="button"`, `aria-expanded`, `@keydown.enter` / `@keydown.space`
- Chevron: `aria-hidden="true"`
- Expanded panel: `id` linked via `aria-controls`

### Motion

- Respect `prefers-reduced-motion: reduce` — disable chevron rotation and smooth scroll

### External links

- All booking + Chase links: `target="_blank" rel="noopener noreferrer"`

## Page Specifications

### index.html

**Purpose:** Daily multi-region fare browser from SLC/PVU with filters, Chase context, and booking links.

**Section order**

1. Navbar (Heatmap, Trends links)
2. Hero + CTA anchor `#flights`
3. Flights section (`x-data` Alpine root)
   - Title + intl/domestic subtitle
   - Deal board (conditional on data)
   - Chase callout
   - Region tablist
   - Filter toggle + collapsible panel
   - Fare card list (one tabpanel per region)
   - Best value box per region (when priced fares exist)
   - Filter hint footer line
4. Scroll-to-top FAB
5. Footer

**Alpine state:** `activeTab`, `maxPrice`, `airlineFilter`, `showFilters`, `intlTabs`, `showScrollTop`

**Regions (8):** DFW, California Coast, Georgia, Cancun, El Salvador, Europe, Japan, South Korea

### heatmap.html

**Purpose:** Calendar grid of best outbound price per day per region.

**Section order**

1. Navbar (back link)
2. Title + active region subtitle
3. Region tablist
4. Tabpanel grid per region
5. Footer

**Alpine state:** `activeRegion`, `heatmapData` (embedded JSON)

### history.html

**Purpose:** 14-day lowest-fare trend line per region.

**Section order**

1. Navbar (Heatmap + Flights links)
2. Title + active region subtitle
3. Region tablist
4. Chart canvas + empty overlay
5. Footer + Chart.js bootstrap script

**Alpine state:** `historyPage()` component with `activeRegion`, `chart`, `hasData`
